# Changelog — RedSigilΔ Type System

This history distinguishes original private engineering milestones from public releases.

## [1.0.1] — First public release candidate (unpublished)

- Added an independently encoded Greek capital Delta (U+0394) to all seven production UFO masters.
- Preserved mathematical increment (U+2206) and white triangle (U+25B3), retaining separate Delta/increment glyph identities and matching initial outlines and widths.
- Updated seven UFO master version values and compiled-version verification expectations from 1.000 to 1.001.
- Updated the production GitHub Actions artifact name to v1.0.1; retained the manual, master-only private build configuration.
- Completed a successful private v1.0.1 production build (GitHub Actions run 42083737306) and independent verification of all 32 outputs.
- Prepared a distinct **public-source** working copy with cleaned source paths, updated technical documentation and MIT licensing for standalone build/verification scripts. These source-package preparation changes were **not** part of the private-font production build.

## [1.0.0] — Original stable foundation (private, October 2026)

- Established three stable font families: RedSigil Display, RedSigil Everyday and RedSigil Mono.
- Delivered seven editable UFO masters and three Designspace files.
- Produced 13 static TTF, three variable TTF and 16 WOFF2 files (32 total).
- Established successful production build and verification evidence (GitHub Actions run 38093292620; source revision d5f28d1105b4ab0c1c405c88bf653c0afd454802).
- Retained SIL Open Font License 1.1, the existing copyright notice and Reserved Font Name RedSigil.

The original v1.0.0 GitHub release is historical and is not replaced or retagged by v1.0.1.
